# Vext

Vext is a personal Android fitness-tracking app.

This public repository exists **only to host APK releases**. Download the latest
build from the [**Releases**](https://github.com/leonx03/vext/releases/latest) page.

## Source code

Active development happens in a private monorepo; the source is not published here.
Release APKs are built and signed there, then published to this repository's Releases
automatically by that monorepo's CI.

## Install

1. Open [Releases](https://github.com/leonx03/vext/releases/latest) on an Android device.
2. Download the `.apk` asset for the version you want.
3. If prompted, allow installation from unknown sources, then open the APK to install.
